4. Group Anagrams — Group words that are anagrams of one another.


5. Top K Frequent Elements — Return the k most frequently occurring numbers.


6. Product of Array Except Self — For each index, return the product of every other value without division.


7. Valid Sudoku — Verify that rows, columns, and 3×3 boxes have no duplicates.


8. Longest Consecutive Sequence — Find the longest run of consecutive integers in an unsorted array.


9. Majority Element — Find the element that occurs more than n / 2 times.


10. Find the Duplicate Number — Find the repeated value in an array containing integers from 1 to n.


11. Missing Number — Find the missing number from the range 0 through n.
